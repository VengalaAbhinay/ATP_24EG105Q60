# Week 2 - JavaScript & Node.js Assignments

##  Overview
This repository contains JavaScript fundamentals, modern ES6+ features, and Node.js module system implementations covered during **Week 2**.

## Folder Structure

### **Array Operations**
- **Simple Operations** (`onlinecourseprocessor.js`, `studentmarkslist.js`, `tempanalyzer.js`)
  - `filter()`, `map()`, `reduce()`, `find()`, `findIndex()`
- **Advanced Operations** (`banktraanaly.js`, `employeeplayroll.js`, etc.)
  - Complex data transformations and calculations

### **Modules Demo**
- **E-Commerce Shopping Cart** - Full modular application with:
  - Product management
  - Cart functionality
  - Payment processing with discount system
  - Clean separation of concerns

- **Task Management System** - With validation modules

### **ES6+ Features**
- **Classes** - Book Library System (`libbooksys.js`)
- **Spread & Rest Operators**
- **Shallow vs Deep Copy**
- **Timer Functions** - Exam portal simulator, OTP countdown
