# Week 4 - HTML & CSS Fundamentals

## 📋 Overview
Static web page development assignments focusing on semantic HTML and basic CSS styling.

## 🗂️ Assignments

### **Assignment 1: Basic Web Pages**

#### `basic-web-page-1.html`
- Simple article layout
- Unordered list with fruits
- Basic semantic structure

#### `basic-web-page-2.html`
- Multi-section layout with:
  - Fruits list (ordered)
  - Vegetables list
  - Cereals & Nuts sections

### **Assignment 2: CSS Styled Page**
- `webpage-simple-css.html`
  - Profile card design for "Pochi The Cat"
  - Introduction section
  - Profile highlights
  - External links
  - Basic styling with CSS

## 🎨 Features
- Semantic HTML5 tags (`<header>`, `<section>`, `<article>`, etc.)
- Basic CSS styling
- Lists and navigation elements
- Simple responsive-friendly structure

## 🚀 How to Run
Just open any `.html` file in your browser.

## ✨ Key Learnings
- Semantic HTML structure
- Basic CSS selectors and styling
- Content organization
- Simple web page layout design
