# Week 1 - JavaScript Fundamentals

##  Overview
This folder contains foundational JavaScript exercises covering variables, conditionals, functions, and array methods.

##  Exercises

### **Day 1: Core JavaScript**

#### **Conditional Logic**
- `bignumamongtwo.js` — Find bigger number using ternary operator
- `bignumamongthree.js` — Find largest among three numbers

#### **Functions & Array Methods**
- `funcarrsearch.js` — Search element in array using `indexOf()`
- `funrecarr.js` — Calculate sum of array using `reduce()`
- `sumofmarks.js` — Sum of student marks
- `smalleleinarr.js` — Find smallest element using `reduce()`
- `funcrec3.js` — Find largest mark using `reduce()`

#### **Array Manipulation**
- `employees.js` — Advanced array operations:
  - Add new employee using `splice()`
  - Remove employee by name
  - Update nested array (marks)

## How to Run

```bash
node Week-1-Day-1/bignumamongtwo.js
node Week-1-Day-1/employees.js
